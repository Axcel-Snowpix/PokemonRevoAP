Save Slot Data
0x8: play_time (double)
0x10: name[10] (wchar_t, maybe longer only 10 is used in english)
0x30: birthday_month[4] (wchar_t, yes pretty sure it's stored as a string despite being a number, length is an assumption)
0x38: birthday_day[4] (wchar_t, yes pretty sure it's stored as a string despite being a number, length is an assumption)
0x40: region_id (uin16_t)
0x42: sub_region_id (uint16_t, ie: California)
0x48: self_introduction[50] (wchar_t, might be slightly longer, but unused in english)

0x0CC : Catchphrase PKMN SHIFT2
0x100 : Catchphrase WIN
0x168 : Catchphrase LOSE
0x1EE : Skin Tone
0x544 : Pass Design *and* Photo Type.
 # i.e. 00 is design 1 with fullbody image, 01 is design 1 with a head shot
0x545 : Pokeball Mark (0x545 : bitflag, 0x80 = Pokeball Mark (Sparkly) / 0x40 locked rental pass)
